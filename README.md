# طيور في بيتي 🐣

دليلك لتربية الطيور في البيت في مصر: فراخ، حمام، سمان، بط، أوز، ورومي.
روتين اليوم، حالة الجو وتنبيهاته على طيورك، طائر عيان، ينفع أأكّلهم ده؟، عدّاد البيض، ومتابعة الرقاد — وبيشتغل من غير نت. من غير حسابات ولا سيرفر: بياناتك على موبايلك بس.

**النسخة التجريبية:** https://seniormohammed1995-hue.github.io/morabbi/

> المحتوى إرشادي ومأخوذ من أدلة السلالات والمراجع العلمية، ولم يراجعه طبيب بيطري. التطبيق لا يشخّص ولا يحدد جرعات أدوية.

## التشغيل
```bash
npm install
npm run dev
```

`npm test` للاختبارات والتحقق من البيانات، `npm run build` للبناء، و `npm run e2e` لاختبارات المتصفح.

التفاصيل الفنية في `CLAUDE.md`، والقرارات في `DECISIONS.md`، والتغييرات في `CHANGELOG.md`.

بيانات الجو من [Open-Meteo.com](https://open-meteo.com/) (CC BY 4.0).
